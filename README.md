# 🎬 StreamVisionBack

Backend para una plataforma web de películas desarrollada como parte de mis prácticas profesionales en **Eviden**. Este servicio gestiona usuarios, autenticación con JWT, conexión con una API externa y el envío de datos al frontend.

---

## 🚀 Tecnologías utilizadas

- **Java 17**
- **Spring Boot**
- **Spring Security (JWT)**
- **JPA / Hibernate**
- **MySQL / PostgreSQL**
- **Maven**
- **API REST**
- Swagger (pendiente de integración)

---

## 📦 Funcionalidades principales

- Registro y login de usuarios con tokens JWT
- Gestión de datos de películas desde API externa
- Endpoints REST seguros con roles y permisos
- Arquitectura modular: controladores, servicios, repositorios
- Estructura limpia siguiendo principios SOLID
